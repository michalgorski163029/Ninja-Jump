# Ninja Jump

*Krótki opis projektu*

Ninja Jump to mobilna gra zręcznościowa 2D tworzona w silniku Unity, przeznaczona na urządzenia z systemem Android. Gra utrzymana jest w klimacie japońskim, z kolorową grafiką i animowaną postacią ninjy.

Celem gracza jest zdobycie jak największej liczby punktów poprzez skakanie i odbijanie się od ścian, jednocześnie unikając niebezpiecznych shurikenów. Z każdym odbiciem gracz zdobywa punkty, a rozgrywka wymaga coraz większej zręczności i refleksu.

Gra zawiera system osiągnięć, zapisywanie najlepszego wyniku, muzykę, ustawienia oraz możliwość ponownego rozpoczęcia rozgrywki po przegranej. Projekt przewiduje wyświetlanie reklam banerowych oraz jednorazowy zakup **Remove Ads**, pozwalający na ich trwałe usunięcie.
